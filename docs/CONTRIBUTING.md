# Contributing

## Before contributing
Read `AGENTS.md`, `PRODUCT_SPEC.md`, `ARCHITECTURE.md`, `SECURITY.md`, and `CODING_STANDARDS.md`.

## Changes
- Open an issue or describe the problem and acceptance criteria.
- Keep pull requests focused.
- Include tests and documentation.
- Explain platform-specific behaviour.
- Identify permission requirements and destructive effects.
- Do not include generated binaries unless requested by release policy.

## Pull request checklist
- [ ] Scope and behaviour are clear.
- [ ] No unreviewed dependency added.
- [ ] Windows/Linux implications considered.
- [ ] Safety and permission cases handled.
- [ ] Tests added/updated.
- [ ] Formatting and static checks pass.
- [ ] Documentation and changelog updated.
- [ ] No unsupported performance or security claims.
